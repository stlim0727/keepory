# v1.4.1

TikTok preview recovery and tag sync reliability improvements.

## English

- TikTok previews: recovered title, caption, and cover images when standard metadata is unavailable.
- Tag sync stability: preserved newly added tags and folders across overlapping cloud syncs.
- Sync lifecycle: prevented background sync callbacks from running after screen unmount.

## 한국어

- 틱톡 미리보기 복구: 메타데이터가 제한된 틱톡 링크에서도 제목, 캡션 및 커버 이미지를 정상적으로 복구합니다.
- 태그 동기화 안정성: 동기화 도중 새로 추가된 태그와 폴더가 일시적으로 사라지는 현상을 방지했습니다.
- 동기화 수명 주기 개선: 화면 언마운트 후 불필요한 백그라운드 동기화 콜백이 실행되지 않도록 개선했습니다.

## Detailed changes (English)

- TikTok preview recovery: added a bounded JSON fallback parser targeting rehydration payload data when oEmbed or OpenGraph tags are stripped or unavailable, restoring video captions and cover previews.
- Tag sync stability: layered acknowledged tag additions similarly to deletions, keeping local tags visible while older remote snapshots are processed until cloud confirmation arrives.
- Sync coordinator guard: added provider lifetime verification to prevent coalesced sync callbacks from executing after unmount.

## 상세 변경 사항 (한국어)

- 틱톡 미리보기 복구: OpenGraph 또는 oEmbed 태그가 누락된 틱톡 링크에서 리하이드레이션 데이터를 분석하는 안전한 폴백 파서를 추가하여 영상 제목/캡션과 커버 이미지를 복구합니다.
- 태그 동기화 안정성: 확인된 태그 추가 작업을 삭제 작업과 유사하게 계층화하여, 이전 원격 스냅샷이 수신되더라도 클라우드 확인이 완료될 때까지 로컬 태그가 화면에서 사라지지 않도록 보호합니다.
- 동기화 수명 주기 개선: 프로바이더 생명주기 검사를 추가하여 화면 언마운트 후 불필요하게 지연된 동기화 콜백이 실행되는 것을 방지합니다.
