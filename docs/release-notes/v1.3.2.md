# Keepory v1.3.2

Photo bookmark sync improvements, interactive clipboard image pasting, share timestamp preservation, and inbox relative time display since v1.3.1.

## English

- Photo bookmark sync: Resolved wildcard image MIME types so shared photos from external apps sync reliably to cloud storage.
- Interactive image paste: Tap the empty image placeholder on the Add screen to directly paste copied photos from the clipboard.
- Accurate share timestamps: Preserves the original timestamp when sharing links or images from external apps.
- Dynamic relative time: Inbox bookmarks now update relative time (e.g. minutes ago) in real time.
- Storage stability: Hardened local file writes and preview cache persistence.

## 한국어

- 사진 북마크 동기화 개선: 외부 앱에서 공유된 사진의 MIME 타입을 정확히 감지하여 클라우드에 안정적으로 동기화합니다.
- 편리한 이미지 붙여넣기: 추가 화면의 이미지 영역을 탭하여 클립보드 사진을 바로 붙여넣을 수 있습니다.
- 공유 시간 보존: 외부 앱에서 공유할 때 원본 공유 시각을 그대로 유지합니다.
- 실시간 상대 시간 표시: 인박스 목록에서 방금 전, 몇 분 전 등 상대 시간이 실시간으로 갱신됩니다.
- 앱 안정성 향상: 로컬 파일 및 미리보기 캐시 저장 안정성을 강화했습니다.
