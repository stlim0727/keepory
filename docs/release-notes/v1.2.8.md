# Keepory v1.2.8

Bug fixes since v1.2.7.

## English

- Improved sync reliability when you edit a bookmark while an earlier change is still syncing.
- Fixed opening and dismissing Add while offline on the web app.
- Improved Google Maps link previews to recover place details more reliably.

## 한국어

- 이전 변경 사항을 동기화하는 중 북마크를 수정해도 최신 변경 사항이 유지되도록 개선했습니다.
- 웹 앱에서 오프라인 상태로 추가 화면을 열고 닫을 때 발생하던 문제를 수정했습니다.
- Google 지도 링크 미리보기에서 장소 정보를 더 안정적으로 불러오도록 개선했습니다.

## Provenance

Includes #950 (queued sync mutation preservation), #951 (offline web routes),
and #952 (Google Maps preview recovery). Android uses an EAS production AAB;
the sideload APK is a separate artifact.
