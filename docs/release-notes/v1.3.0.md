# Keepory v1.3.0

A refreshed library and clearer sharing feedback, with improvements since v1.2.10.

## English

- Refreshed bookmark cards, search, filters, and typography for a cleaner library.
- Made AI suggestions easier to review and bulk bookmark actions easier to reach.
- Fixed saving images shared from Google Photos on Android.
- Added a dismissible “Already in Keepory” ribbon below the Inbox header, with
  a shortcut to the existing bookmark. Duplicate feedback now also appears when
  processing shares received in the background.
- Improved share confirmations and connection reliability.

## 한국어

- 북마크 카드, 검색, 필터와 글꼴을 새롭게 정리해 보관함을 더 편하게 볼 수 있습니다.
- AI 추천을 검토하기 쉽게 다듬고 여러 북마크의 일괄 작업을 개선했습니다.
- Android에서 Google 포토로 공유한 이미지가 저장되지 않던 문제를 수정했습니다.
- 받은함 헤더 아래에 닫을 수 있는 중복 공유 알림을 추가했습니다. 알림에서 기존
  북마크를 바로 열 수 있으며, 백그라운드로 받은 공유도 중복 여부를 알려드립니다.
- 공유 확인 알림과 연결 안정성을 개선했습니다.

## Web

- Wide browser layouts can show the library and bookmark details side by side.
- Improved Korean text wrapping and web brand rendering.

## Google Play notes

`v1.3.0.play.json` contains separate `en-US` and `ko-KR` Publisher API texts,
each below the 500-character limit. Apply and verify these through
`scripts/play-production-release.mjs` when promoting the exact internal AAB.
Generated Fastlane changelogs alone do not establish localized Play notes.

## Provenance

Changes since stable tag `v1.2.10` (`b067e34`), including the library redesign
(#1008–#1014), web brand fix (#1024), Google Photos image capture fix (#1025),
and persistent duplicate-share feedback (#1026). This release introduces a new
minor version because it includes library UI features as well as bug fixes.

Android requires a signed EAS production AAB for `com.keepory.app`; the
tag-triggered sideload APK is a separate artifact. Release preparation does not
establish Play publication or native device acceptance.
