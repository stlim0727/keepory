# v1.4.0

Clipboard paste for every capture type, photo-sharing fixes, and in-app problem
reporting. This release supersedes `v1.3.2`, which was published only to the
Play internal track; users upgrading from production `v1.3.1` receive both sets
of changes.

## English

- Paste anywhere: Paste buttons beside the URL field, in the note editor, and on the image picker.
- Memo paste with automatic Markdown detection.
- Smart link paste splits copied text into link, title, and notes.
- Photo sync: wildcard image types now sync reliably.
- Share timestamps and live relative times are preserved.
- Report crashes and save failures from the in-app prompt.
- Stability: safer local file and preview cache writes.

## 한국어

- 어디서나 붙여넣기: URL 입력란 옆, 노트 편집기, 이미지 선택 영역에 붙여넣기 버튼이 있습니다.
- 메모 붙여넣기와 Markdown 자동 감지.
- 스마트 링크 붙여넣기: 링크, 제목, 노트로 자동 분리.
- 사진 동기화: 와일드카드 이미지 타입도 안정적으로 동기화.
- 공유 시각과 실시간 상대 시간 유지.
- 앱 안에서 오류와 저장 실패 신고.
- 로컬 파일과 미리보기 쓰기 안정성 개선.

## Detailed changes (English)

- Paste anywhere in Add: dedicated Paste buttons now sit next to the URL field, inside the note editor, and on the image picker — no long-press menus.
- Paste a memo: clipboard text can be pasted directly into a note, with Markdown detected automatically.
- Smarter link paste: copied text containing a URL is split into link, title, and notes for review before saving.
- Clear paste feedback: dedicated messages explain an empty clipboard, a denied read, a missing image, or text over the 10,000-character limit.
- Photo sync: wildcard image MIME types from other apps are resolved, so shared photos sync reliably to cloud storage.
- Share timestamps and live relative times: saves keep the original share time, and inbox relative times update as time passes.
- Report a problem: failure screens now offer a diagnostic log send action so defects can be reported in place.
- Stability: local file and preview-cache writes are awaited and their failures handled instead of surfacing as unhandled rejections.

## 상세 변경 사항 (한국어)

- 어디서나 붙여넣기: URL 입력란 옆, 노트 편집기 안, 이미지 선택 영역에 전용 붙여넣기 버튼이 추가되어 길게 누를 필요가 없습니다.
- 메모 붙여넣기: 클립보드 텍스트를 노트에 바로 붙여넣을 수 있으며 Markdown이 자동으로 감지됩니다.
- 스마트 링크 붙여넣기: URL이 포함된 복사 텍스트를 링크, 제목, 노트로 나누어 저장 전에 확인할 수 있습니다.
- 명확한 붙여넣기 안내: 빈 클립보드, 읽기 거부, 이미지 없음, 10,000자 초과 시 각각 알맞은 메시지를 표시합니다.
- 사진 동기화 개선: 외부 앱의 와일드카드 이미지 MIME 타입을 처리하여 공유 사진이 클라우드에 안정적으로 동기화됩니다.
- 공유 시각과 실시간 상대 시간: 저장 시 원본 공유 시각을 유지하고, 인박스의 상대 시간이 실시간으로 갱신됩니다.
- 문제 신고: 실패 화면에서 진단 로그를 바로 보낼 수 있는 버튼을 제공합니다.
- 안정성: 로컬 파일과 미리보기 캐시 쓰기를 대기하고 실패를 처리하여 처리되지 않은 거부로 남지 않습니다.
