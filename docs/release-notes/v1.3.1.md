# Keepory v1.3.1

Full-screen photo viewing, responsive image bookmark previews, and improved AI localization since v1.3.0.

## English

- Full-screen photo viewer: Tap on image bookmark previews to view full uncropped photos and share them directly.
- Responsive image preview: Bookmark cards now dynamically match the photo aspect ratio in detail view.
- Localized AI suggestions: AI-suggested tags and keywords now consistently follow your preferred language.
- Smarter metadata: Improved title and keyword extraction when descriptions are missing.
- Performance and stability improvements across sync and native workflows.

## 한국어

- 전체 화면 사진 뷰어: 이미지 북마크를 탭해 원본 비율 그대로 전체 화면으로 확인하고 바로 공유할 수 있습니다.
- 반응형 이미지 미리보기: 상세 화면에서 사진 비율에 맞춰 잘림 없이 카드가 표시됩니다.
- 언어 맞춤 AI 추천: AI 추천 태그와 핵심 키워드가 사용자의 언어 설정에 맞춰 일관되게 생성됩니다.
- 메타데이터 추출 개선: 웹페이지 설명이 누락된 경우에도 제목을 기반으로 정확하게 분석합니다.
- 앱 안정성 및 성능 최적화.

## Google Play notes

`v1.3.1.play.json` contains separate `en-US` and `ko-KR` Publisher API texts,
each below the 500-character limit. Apply and verify these through
`scripts/play-production-release.mjs` when promoting the exact internal AAB.
Generated Fastlane changelogs alone do not establish localized Play notes.

## Provenance

Changes since stable tag `v1.3.0` (`7bca5e3`), including full-screen photo viewing
(#1037), AI enrichment localization (#1036, #1038), runner-local CI AAB build (#1039),
and coordinated Expo SDK 58 runtime updates (#1029–#1035).

Android requires a signed EAS production AAB for `com.keepory.app`; the
tag-triggered sideload APK is a separate artifact. Release preparation does not
establish Play publication or native device acceptance.
