# v1.4.2

Inbox and Trash stability fixes plus dependency maintenance.

## English

- Inbox cards keep their preview area when an image is missing or fails to load.
- Folder and tag pills on Inbox rows now apply the matching filter in card and list views.
- Clearing Trash on web uses a browser confirmation; native keeps the destructive alert.
- Fixed an Android Inbox crash when changing scope.
- Updated Expo, Sentry, PostHog, and other dependencies.

## 한국어

- 인박스 카드는 이미지가 없거나 불러오지 못해도 미리보기 영역을 유지합니다.
- 인박스 행의 폴더/태그 칩을 누르면 카드 및 목록 보기에서 해당 필터가 적용됩니다.
- 웹 휴지통은 브라우저 확인 창으로 비우며, 네이티브는 기존 경고 창을 유지합니다.
- 범위 변경 시 발생하던 안드로이드 인박스 충돌을 수정했습니다.
- Expo, Sentry, PostHog 등 의존성을 업데이트했습니다.

## Detailed changes (English)

- STASH-8B: link cards reserve the same preview area on missing or failed images and fall back to the bookmark icon; list rows already reserved a thumbnail slot.
- STASH-8A: React Native `Alert`'s destructive callback never fired on Web, so Trash uses `window.confirm` there while native keeps the destructive alert. A direct visit to Trash can clear the list without a back entry.
- STASH-89: folder and tag pills on Inbox rows were static labels; they now apply the corresponding Inbox filter in both Cards and List without opening bookmark detail.
- STASH-88: the Android crash stack ended in Inbox's only `setParams` call; scope changes now update local state and only clear a stale facet URL on Web.
- Dependency maintenance: Expo modules (font, web browser, linking, constants, network, crypto), `jest-expo`, `react-native-enriched-markdown`, `posthog-react-native`, `@sentry/react-native`, and `actions/setup-java` were upgraded. Agent docs now reference the global PR follow-through contract (#1073).

## 상세 변경 사항 (한국어)

- STASH-8B: 이미지가 없거나 로드에 실패해도 링크 카드가 동일한 미리보기 영역을 유지하고 북마크 아이콘으로 대체합니다. 목록 행은 이미 썸네일 영역을 확보하고 있었습니다.
- STASH-8A: 웹에서 React Native `Alert`의 파괴적 동작 콜백이 실행되지 않아 휴지통은 브라우저 확인 창을 사용하고, 네이티브는 기존 경고 창을 유지합니다. 휴지통에 직접 방문해도 뒤로 가기 없이 목록을 비울 수 있습니다.
- STASH-89: 인박스 행의 폴더/태그 칩은 정적 라벨이었으나, 이제 카드 및 목록 보기에서 상세 화면을 열지 않고 해당 필터를 적용합니다.
- STASH-88: 안드로이드 충돌 스택이 인박스의 유일한 `setParams` 호출에서 종료되었습니다. 범위 변경은 로컬 상태만 갱신하며, 웹에서만 오래된 패싯 URL을 정리합니다.
- 의존성 유지보수: Expo 모듈(글꼴, 웹 브라우저, 링킹, 상수, 네트워크, 암호화), `jest-expo`, `react-native-enriched-markdown`, `posthog-react-native`, `@sentry/react-native`, `actions/setup-java`를 업그레이드했습니다. 에이전트 문서는 전역 PR 팔로스루 규칙(#1073)을 참조합니다.
