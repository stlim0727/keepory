# Keepory v1.2.9

Updates and improvements since v1.2.8.

## English

- Streamlined first-save onboarding and cross-device sync in empty inbox.
- Added short-form video metadata extraction and error page filtering.
- Moved bookmark actions to the top of detail screen for quicker access.

## 한국어

- 빈 받은함에서 첫 저장 동작과 기기 간 동기화 안내를 개선했습니다.
- 틱톡 등 숏폼 영상 메타데이터를 지원하고 오류 페이지 제목을 필터링합니다.
